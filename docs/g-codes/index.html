G-code and M-code reference: Fanuc lathe and mill, Haas

What each G and M code does on each control, as CNC Simulator runs it. The same explanations appear in the app’s learning mode when you hover a code in the program.

Fanuc 0i-TF lathe (G-code system B, Romi GL)

G codes

CodeWhat it does
G00Rapid positioning at the machine's top speed, not cutting. Use it only in free air: a rapid into the stock is a crash.
G01Straight cut at feed F to the programmed point.
G02Clockwise arc to the end point, seen from the plane's positive axis. Center with I/J/K (from the start point) or radius R.
G03Counterclockwise arc to the end point. Center with I/J/K (from the start point) or radius R.
G04Dwell: waits P (milliseconds, no decimal point) or X/U (seconds) without moving.
G07.1Cylindrical interpolation. Cylindrical interpolation: C is unrolled on the diameter, for slots around a shaft.
G10Programmable data input (work offsets L2/L20). Writes offsets from the program: L2/L20 work offsets, L10–L13 tool offsets (lathe: P n wear, P 10000+n geometry).
G12.1Polar coordinate interpolation X/C. Polar interpolation on: X (diameter) and C become a flat XC plane, for milling the face of a part with a live tool.
G13.1Polar interpolation off.
G17Plane XY for arcs and cutter compensation (machining centers).
G18Plane ZX for arcs and compensation (the turning plane on lathes).
G19Plane YZ for arcs and compensation.
G20Units in inches.
G21Units in millimeters.
G28Return to the machine reference point through the programmed point (G91 G28 Z0 goes straight up from where it is).
G32Thread cutting. Thread cutting move: a straight cut synchronized with the spindle, F = lead.
G40Cancels cutter (or nose) radius compensation. Cancel with a move away from the part.
G41Cutter radius compensation to the left of the path (climb milling on outside contours). Radius from D (lathe: nose radius of the T offset). Start it with a straight move.
G42Cutter radius compensation to the right of the path. Radius from D (lathe: nose radius). Start it with a straight move.
G53Move in machine coordinates for this block only, ignoring work offsets and tool length.
G54Selects a work offset (part zero) from the OFFSET table: G54–G59, G54.1 P n (Haas G154 P n).
G55Selects a work offset (part zero) from the OFFSET table: G54–G59, G54.1 P n (Haas G154 P n).
G56Selects a work offset (part zero) from the OFFSET table: G54–G59, G54.1 P n (Haas G154 P n).
G57Selects a work offset (part zero) from the OFFSET table: G54–G59, G54.1 P n (Haas G154 P n).
G58Selects a work offset (part zero) from the OFFSET table: G54–G59, G54.1 P n (Haas G154 P n).
G59Selects a work offset (part zero) from the OFFSET table: G54–G59, G54.1 P n (Haas G154 P n).
G65Macro call (G65 P n): runs program O n once, with the letters as arguments (A → #1, B → #2, …).
G66Modal macro call: the macro runs after every move until it is cancelled.
G67Cancels the modal macro call.
G70Finishing cycle (G70 P Q): runs the shape between blocks N P and N Q once, with the finishing feed, after G71/G72/G73.
G71Longitudinal roughing. Stock removal in turning (G71). First block: U depth of cut (radius) and R retract. Second block: P and Q are the N numbers of the first and last block of the finished shape, U/W the finishing allowance in X (diameter) and Z, F the roughing feed.
G72Face roughing. Stock removal in facing (G72): like G71, but the passes run along X, stepping in Z (W depth).
G73Pattern repeating. Pattern repeating (G73): the finished shape is followed several times, closer each time; for forged or cast parts. U/W relief, R number of passes.
G74Face peck drilling / turning with peck. Peck cycle along Z (face grooving or deep drilling on the axis).
G75Grooving / facing. Peck grooving along X.
G76Multiple threading (G76). First block: P (passes of finish, chamfer, angle, as 6 digits), Q minimum depth, R finishing allowance. Second block: X Z thread root at the end, P thread height, Q first depth (microns), F lead.
G77Single turning cycle: rapid in, cut to X Z, out and back, in one block. R makes a taper. Repeat with only the next X.
G78Single threading cycle: one pass per block, F = lead. Program the next diameter for each pass.
G79Single facing cycle: like the turning cycle, but cutting along X. R makes a taper in Z.
G80Cancels the active drilling cycle: the next X/Y no longer drills.
G83Face drilling. Drilling cycle: rapid to R, feed to Z, rapid out (G82 with a dwell P at the bottom). Repeats at each X/Y until G80.
G84Face tapping. Tapping cycle: feed F must be the pitch × rpm (or the pitch with feed per revolution); the spindle reverses at the bottom.
G85Boring cycle: feed in to Z and out (how it comes out, feed or rapid, stopped or turning, depends on the code).
G87Radial drilling with a live tool, along X toward the axis.
G88Radial tapping with a live tool.
G90Absolute coordinates: every value is a position from the work zero.
G91Incremental coordinates: every value is a distance from where the tool is.
G92Set origin or max spindle speed. Sets the current position as the given coordinates (G92 on mills, G50 on system A lathes); on lathes it also limits the spindle speed with S.
G94Feed F in mm/min.
G95Feed F in mm per spindle revolution (the usual on lathes).
G96Constant cutting speed: S is in m/min and the rpm rises as the diameter gets smaller. Limit it with G50/G92 S.
G97Constant spindle speed: S in rpm.
G98After each hole the tool returns to the initial level (where the cycle started): safe over clamps.
G99After each hole the tool returns to the R level: faster, for a flat part without obstacles.

M codes

CodeWhat it does
M00Program stop: the machine stops until cycle start (to measure, clean chips, turn the part).
M01Optional stop: stops only with the M01 key on.
M02End of program.
M03Spindle, or live tool when S2= is given, clockwise. Spindle on, clockwise (S sets the speed).
M04Spindle on, counterclockwise.
M05Also releases the M85 brake. Spindle stop.
M08Coolant on.
M09Coolant off.
M15Reverse coupling shaft rotation (counter-clockwise). Machine function with no effect on the path.
M16Reverse coupling shaft rotation (clockwise). Machine function with no effect on the path.
M19Spindle orientation / enable C axis. C axis mode: the spindle becomes a positioning axis.
M30End of program and back to the start.
M85High-torque brake; G0 C or M5 release it. Clamps the axis (brake) to cut without it turning.
M98Calls subprogram P (O number); L or the leading digits of P repeat it.
M99End of subprogram: returns to the block after the call.
